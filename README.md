## 🛠️ Technology & Services

The website was developed using **Google AI Studio**, with integrations and services including:

- Google Gemini API — AI assistant functionality
- Firebase Authentication — User login and account verification
- Cloud Firestore — Website data and administrator records
- Firebase Storage — File and image storage, where configured
- Resend — Transactional email notification integration
- GitHub — Source code management

Additional frontend and backend dependencies are defined in the project source code.

## 🔐 Administrator Management

The website includes an administrator management system designed to support:

- Secure Owner login
- Administrator account registration
- Email verification
- Owner approval of administrator requests
- Role-based access permissions
- Content management
- Administrator account management
- Direct Inquiry management

Administrative functionality is restricted to authorized accounts.

## 🔒 Security

The application is designed to keep sensitive operations on the server.

Security practices include:

- Firebase-based authentication
- Administrator authorization
- Secure environment variables
- Protected backend operations
- Restricted access to private data

**Important:** API keys, passwords, service-account credentials, and other private secrets must never be committed to this repository.
